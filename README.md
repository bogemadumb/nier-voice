# Nier Voice — голосовой ввод для macOS

Держишь клавишу — говоришь — слова появляются по ходу речи в капсуле над экраном; отпустил — текст
вставлен туда, где стоит курсор, в любом приложении. Нативное приложение в меню-баре на Swift + SwiftUI,
собирается без Xcode.

## Возможности

- **Потоковое распознавание** — Deepgram Nova-3 по WebSocket: черновые слова приходят во время речи
  и «затвердевают» по мере подтверждения; русский с английскими терминами внутри фразы (`language=multi`).
- **Запасной движок** — Groq whisper-large-v3-turbo чанками (бесплатный суточный лимит).
- **Полировка текста** — LLM через Groq убирает «эээ», повторы и оговорки, расставляет знаки. Жёсткий
  дедлайн 4 секунды: не успела — вставляется сырой текст, диктовка не теряется. Режимы: как сказано /
  прибрать / деловой / разговорный; свой словарь терминов уходит и в распознавание, и в полировку.
- **Глобальная клавиша** — удержание правой ⌥ (или ⌘/⌃/⇧) через CGEventTap; режим удержания или переключателя,
  автостоп по тишине, Esc — отмена.
- **Вставка** — через буфер обмена и синтетический ⌘V с последующим восстановлением прежнего содержимого буфера.
- **Капсула** — стеклянная панель macOS 26 без перехвата фокуса, ореол «дышит» от громкости, живая волна микрофона.
- **Настройки** — пять разделов (диктовка, управление, текст, история, система) с живым статусом разрешений;
  история последних 60 диктовок; автозапуск при входе.

## Устройство

| Файл | Роль |
|---|---|
| `AppDelegate.swift` | жизненный цикл: клавиша → запись → движок → полировка → вставка |
| `HoldHotkey.swift` | глобальный перехват модификатора (CGEventTap на `flagsChanged`) |
| `AudioCapture.swift` | AVAudioEngine → PCM 16 кГц моно для движков, уровень громкости для ореола |
| `TranscriptionEngine.swift`, `DeepgramEngine.swift`, `GroqEngine.swift` | общий протокол и две реализации |
| `Polisher.swift` | полировка с дедлайном и промптом под выбранный стиль |
| `TextInserter.swift` | вставка через буфер с восстановлением |
| `CapsulePanel.swift`, `CapsuleView.swift`, `Waveform.swift`, `Theme.swift` | интерфейс капсулы |
| `Secrets.swift` | ключи API в `~/Library/Application Support/NierVoice/keys.json` с правами 600 |

Почему ключи не в связке ключей: при ad-hoc подписи каждая пересборка меняет идентичность приложения,
и macOS заново спрашивает пароль к связке. Файл с правами 600 в контейнере пользователя — осознанный компромисс.

`prototype/capsule.html` — HTML-прототип трёх вариантов дизайна капсулы, из которого выбран итоговый.

## Сборка

```sh
./build.sh                       # swift build -c release, бандл, подпись, установка в /Applications
APP=/tmp/NierVoice.app ./build.sh
./make-cert.sh                   # необязательно: постоянный самоподписанный сертификат,
SIGN_IDENTITY="Nier Voice Self" ./build.sh   # чтобы разрешения не слетали после пересборок
```

Требования: macOS 26+, Swift 6 (Command Line Tools достаточно). На SDK macOS 27 в Command Line Tools нет
плагина `SwiftUIMacros`, поэтому `build.sh` сам берёт SDK 26.x, если Xcode не установлен.
После первого запуска нужно выдать разрешения «Микрофон» и «Универсальный доступ», а в настройках — вставить
ключи Deepgram и/или Groq.
